# Design Assets

Assets received from UX design team to integrate with the frontend codebase. Any code files in this folder are NOT ACTUALLY PART OF THE APP and should not interact with any code in `frontend` or `backend`.

## V2 - rev. 2026-07

- a giant TSX file - artifact generated by Claude.

## V3 - rev. 2026-08

Structured with 3 subfolders.

- `design` - for viewing the new design in a browser
  - `Commons Fabric Calendar.html` - HTML page for interactive wireframe
  - `Commons Fabric Design System.html` - HTML page for new design system
- `screenshots` - images of updated design
- `src` - Claude-generated code for interactive wireframe
  - `components` - `AboutView`, `CalendarPanel`, `CreateAccountModal`, `CreateEventModal`, `DirectoryView`, `EventCardGrid`, `EventDetailModal`, `Footer`, `Header`, `Icons`, `LoginModal`, `ModalShell`, `MonthGrid`, `OrgFilterDropdown`, `OrgProfileView`, `TimelineGrid`
  - `CommonsFabricCalendar.tsx` - main TSX file
  - (helpers) - `data.ts`, `timeline.ts`, `tokens.ts`, `types.ts`, `useHoverStyle.ts`, `utils.ts`
